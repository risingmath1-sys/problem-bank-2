✅ 새로 추가된 배치 파일 (추천):

1. 서버클라이언트시작.bat ⭐ 추천
   → Python 확인 → 의존성 설치 → 서버 시작 → 브라우저 열기 (자동화)
   → 매번 이것 실행하면 됨

2. 진단_웹서버.bat
   → Python, FastAPI, Firebase 설치 상태 진단
   → "안 먹는다"고 하면 이것 실행 후 [X] 항목 해결

3. 포트정리.bat
   → 포트 8000 충돌 시 사용
   → "주소가 이미 사용 중입니다" 에러 났을 때

📋 사용법:

1. 서버클라이언트시작.bat 더블클릭
   (Python 확인 → 의존성 자동 설치 → 서버 시작 → 브라우저 자동 열음)

2. 브라우저에 로그인 화면이 나타나면 성공 ✓

3. 사용 중 에러 발생하면:
   → 포트정리.bat (포트 충돌 시)
   → 진단_웹서버.bat (상세 진단)

4. 종료: 검은색 서버 창에서 Ctrl+C
